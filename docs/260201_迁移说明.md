# QData 目录结构优化和迁移说明

## 优化概述

将原本分散在 `utils` 目录下的股票数据相关功能整合到独立的 `qdata` 库中，形成专门针对 akshare、jqdata、tushare 等数据源的专属库。

## 目录结构变化

### 优化前（旧结构）

```
AIQuant/
├── utils/
│   ├── stockapi_manager.py      # API资源管理器
│   ├── stockapi_ai_selector.py  # AI选择器
│   ├── data_dict_mapper.py      # 数据字典转换器
│   └── util_akshare.py          # akshare工具函数
└── resource/
    └── stockapi/                # API文档（仅akshare）
```

### 优化后（新结构）

```
AIQuant/
├── QData/                       # 独立的量化数据库
│   ├── __init__.py             # 统一入口
│   ├── core/                   # 核心模块
│   │   ├── __init__.py
│   │   ├── manager.py         # API资源管理器（支持多数据源）
│   │   ├── selector.py        # AI智能选择器（支持多数据源）
│   │   ├── mapper.py          # 数据字典转换器（支持多数据源）
│   │   └── query.py          # 自然语言查询接口
│   ├── providers/             # 数据源提供者
│   │   ├── __init__.py
│   │   ├── akshare.py         # Akshare提供者
│   │   ├── jqdata.py          # JQData提供者
│   │   └── tushare.py         # Tushare提供者
│   ├── utils/                 # 工具函数
│   │   ├── __init__.py
│   │   └── helpers.py         # 辅助函数
│   ├── akshare/               # Akshare资源
│   │   ├── api_overview.md
│   │   └── stockapi/          # API文档
│   ├── jqdata/                # JQData资源
│   ├── tushare/               # Tushare资源
│   └── docs/                  # 文档
│       ├── API选择方式对比分析.md
│       └── 迁移说明.md
└── utils/                      # 向后兼容层
    ├── stockapi_manager.py     # 重定向到qdata
    ├── stockapi_ai_selector.py  # 重定向到qdata
    └── data_dict_mapper.py     # 重定向到qdata
```

## 主要优化点

### 1. 统一的数据源管理

**优化前：**
- 只支持 akshare
- 资源目录分散

**优化后：**
- 支持多数据源（akshare、jqdata、tushare）
- 统一的资源目录结构
- 每个数据源有独立的提供者

### 2. 统一的接口设计

**优化前：**
```python
from utils.stockapi_manager import get_stockapi_manager
from utils.data_dict_mapper import ak_dict_to_quantus_dict
```

**优化后：**
```python
from QData import get_api_manager, to_quantus_dict

# 支持多数据源
manager = get_api_manager(provider="akshare")
manager = get_api_manager(provider="jqdata")
manager = get_api_manager(provider="tushare")
```

### 3. 自然语言查询接口

**新增功能：**
```python
from QData import query

# 通过自然语言查询API
result = await query("获取600000的20日close数据", provider="akshare")
```

### 4. 数据源提供者模式

**优化前：**
- 工具函数分散在多个文件

**优化后：**
- 每个数据源有独立的提供者类
- 统一的方法接口
- 便于扩展新数据源

## 迁移指南

### 导入路径变化

#### 旧代码
```python
from utils.stockapi_manager import get_stockapi_manager
from utils.stockapi_ai_selector import StockAPIAISelector
from utils.data_dict_mapper import ak_dict_to_quantus_dict
from utils.util_akshare import format_date_param
```

#### 新代码
```python
from QData.core.manager import get_api_manager
from QData.core.selector import APISelector
from QData.core.mapper import ak_dict_to_quantus_dict
from QData.utils.helpers import format_date_param
```

#### 或者使用统一入口
```python
from QData import (
    get_api_manager,
    APISelector,
    ak_dict_to_quantus_dict,
    AkshareProvider
)
```

### API变化

#### 获取管理器

**旧代码：**
```python
manager = get_stockapi_manager()
```

**新代码：**
```python
manager = get_api_manager(provider="akshare")
```

#### AI选择器

**旧代码：**
```python
selector = StockAPIAISelector()
```

**新代码：**
```python
selector = APISelector(provider="akshare")
```

### 向后兼容

为了保持向后兼容，旧的导入路径仍然可用：

```python
# 这些导入仍然可以工作，但会重定向到qdata
from utils.stockapi_manager import get_stockapi_manager
from utils.data_dict_mapper import ak_dict_to_quantus_dict
```

**注意：** 建议逐步迁移到新的 `qdata` 导入路径。

## 新功能

### 1. 自然语言查询

```python
from QData import query

# 查询API（不执行）
result = await query("获取600000的20日close数据", provider="akshare")

# 查询并执行API
result = await query(
    "获取600000的20日close数据",
    provider="akshare",
    execute=True
)
```

### 2. 多数据源支持

```python
from QData import get_api_manager

# 支持多个数据源
for provider in ["akshare", "jqdata", "tushare"]:
    manager = get_api_manager(provider=provider)
    apis = manager.list_available_apis()
    print(f"{provider}: {len(apis)} 个API")
```

### 3. 数据源提供者

```python
from QData.providers.akshare import AkshareProvider

provider = AkshareProvider()

# 检测是否需要使用akshare
info = provider.detect_function(markdown_content)

# 转换为统一格式
data = provider.convert_to_quantus(ak_data)

# 生成代码
code = provider.generate_code(api_name, api_doc, params)
```

## 优势总结

1. **模块化设计**
   - 核心功能、提供者、工具函数分离
   - 便于维护和扩展

2. **多数据源支持**
   - 统一的接口设计
   - 易于添加新数据源

3. **自然语言查询**
   - 通过自然语言找到API
   - 支持AI智能选择

4. **统一数据格式**
   - 所有数据源转换为 quantus_dict
   - 便于后续处理

5. **向后兼容**
   - 保持旧代码可用
   - 平滑迁移
